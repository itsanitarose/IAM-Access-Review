## 03. Preventive Controls

<br>

My recommendations focus on **preventing these issues from recurring**, not just fixing the accounts identified.

| Account Type | Recommendation | Supporting Documentation |
|---|---|---|
| **Leavers** | Link HR termination dates to automatic account deactivation and access removal. Verify completion and flag any access left active. | [Lifecycle Workflows](https://learn.microsoft.com/en-us/entra/id-governance/understanding-lifecycle-workflows) |
| **Contractors** | Set access to end with the approved contract period. Require a documented extension before allowing access to continue. | [Access Package Lifecycle Policies](https://learn.microsoft.com/en-us/entra/id-governance/entitlement-management-access-package-lifecycle-policy) |
| **Privileged Access** | Require business justification and approval for Admin access. Conduct quarterly access recertification with the application owner and remove privileges no longer needed. | [Privileged Identity Management](https://learn.microsoft.com/en-us/entra/id-governance/privileged-identity-management/pim-configure) |
| Shared Accounts | Replace shared logins with named accounts so activity can be traced to individuals. Confirm staff have the access they need before disabling the shared account. | [Microsoft Learn — Create Individual User Accounts](https://learn.microsoft.com/en-us/azure/cloud-adoption-framework/ready/azure-setup-guide/identity#create-individual-user-accounts) |
| **Orphaned and Dormant Accounts** | Keep an account inventory with named owners and business purposes. Flag accounts with no owner or prolonged inactivity, and review them for deactivation. | [Microsoft Learn — Addressing Inactive Accounts](https://learn.microsoft.com/en-us/entra/identity/monitoring-health/howto-manage-inactive-user-accounts#how-to-address-inactive-users) |
| **Extended Leave** | Have HR and IAM review whether access should be retained, reduced or suspended during leave. Reassess it when the employee returns. | [NHS England — Other leavers](https://www.england.nhs.uk/long-read/smartcards-and-access-controls/#:~:text=Other%20rules%20apply%20when%20staff%20are%20on%20extended%20leave) |
